# AWS Task - 1

## Objective

Create a Windows virtual machine in AWS EC2, connect to it using Remote Desktop Protocol (RDP), open Command Prompt, and display Windows system information.

## Technologies Used

- AWS EC2
- Windows Server
- Remote Desktop Protocol (RDP)
- Windows Command Prompt

## EC2 Instance

A Windows Server 2025 Datacenter EC2 instance was launched using a t3.micro instance type.

## RDP Connection

The Windows EC2 instance was successfully accessed using RDP with the Administrator account.

## System Information

Windows system information was verified using the following Command Prompt command:

```cmd
systeminfo

The command displayed the Windows operating system, version, system manufacturer, system model, processor, memory, and network information.

## Result

The Windows EC2 instance was successfully created, accessed through RDP, and system information was verified using Windows Command Prompt.
